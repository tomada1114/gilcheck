# Getting Started

## Installation

```bash
pip install gilcheck
```

Or with [uv](https://docs.astral.sh/uv/):

```bash
uv add gilcheck
```

## Basic Usage

```python
from gilcheck import add

result = add(1, 2)
print(result)  # 3
```
